# 整蛊网页 · 使用说明

一个纯前端的整蛊小游戏：假加载 → 假报错 → 假修复 → 假权限 → 后台进程 → 假重启 → 系统抽风 → 终局选择。

全程为本地网页模拟：**不联网、不读取本地文件、不申请真实权限、没有音效**。

## 文件结构

```
prank/
├── index.html   入口页面
├── styles.css   全部样式与动效
├── app.js       状态机、弹窗管理器、各幕逻辑
├── demo.html    弹窗组件演示（自检用，可选）
└── README.md    本说明
```

`index.html`、`styles.css`、`app.js` 三个文件必须放在同一目录，缺一个页面就会失效。

## 怎么打开

- 双击 `index.html`，用默认浏览器打开即可。
- 或把完整路径粘贴到浏览器地址栏。
- **快速调试**：地址后加 `?fast`，加载与倒计时提速 4 倍，例如
  `file:///E:/vs.code/vscode.project/front/prank/index.html?fast`
- **弹窗演示**：双击 `demo.html`，会弹出 3 个示例弹窗，用于查看弹窗样式与层级。

## 怎么发给朋友

- **方式一（推荐）**：把整个 `prank` 文件夹压缩成 zip 发过去，对方解压后双击 `index.html`。
- **方式二**：把文件夹上传到任意静态托管（GitHub Pages、Vercel、Netlify 等），直接发链接。
- 不要只发 `index.html`，否则缺少样式和逻辑。

## 怎么退出

1. 右下角极淡的「我认输」小字（鼠标悬停会变清晰）。
2. 连续按 **ESC 5 次**（每次间隔不超过 2 秒，界面没有任何提示）。

「我认输」会弹出「唉~回家吃饭吧你还是」，点「好吧」进入结束页。
ESC×5 在一般画面同样弹出该告别窗；但在第 7 幕「光标拼成 silly」的画面中，ESC×5 会直接进入「再试一次 / 游戏失败」终局页。

终局页只有两个按钮：

- **再试一次**：重新开始整个流程。
- **游戏失败**：弹出模拟 Windows 报错窗（「Windows 资源保护检测到文件损坏」）；点「确定」后会回到初始加载界面，继续循环。

刷新页面 = 完全重置；关闭标签页 = 彻底结束。

## 怎么修改

所有文案和节奏都集中在 `app.js` 的各个 `renderXxx` 函数里。

| 想改什么 | 改哪里 |
|---------|--------|
| 各幕文案、弹窗标题、按钮文字 | `renderError`、`renderRepairAsk`、`renderPermission` 等函数里的 `title` / `body` / `buttons.label` |
| 加载与倒计时节奏 | `app.js` 顶部的 `DURATION` |
| 修复进度停滞范围 | `renderRepairAsk` 里的 `stallAt = 51 + Math.floor(Math.random() * 49)`（当前 51%~99%） |
| 套娃文案 | `renderCloseLoop` |
| 终局两个按钮 | `renderReveal` |
| Windows 报错文案 | `openFakeWindowsError` |
| 告别弹窗文案 | `showGiveUpDialog` |
| 第 7 幕系统报错文案 / 数量 | `WIN_ERROR_SAMPLES` 与 `renderGlitch` 里的 `anchors`、`perCluster`、光标数量 |
| 第 7 幕光标拼出的单词 / 点阵字体 | `renderGlitch` 里的 `morphToWord('silly', ...)` 与 `WORD_FONT_WIDE` / `WORD_FONT_COMPACT` |
| 同屏弹窗上限 | 弹窗管理器里的 `MAX`（当前 3） |
| 配色、圆角、字体 | `styles.css` 顶部 `:root` 变量 |
| 移动端布局 | `styles.css` 底部 `@media (max-width: 480px)` |

注意：修改时不要加入摄像头、麦克风、全屏锁定、真实权限申请、真实系统弹窗等真实伤害性功能。

| # | 检查项 | 预期 |

| 1 | 打开页面 | 进度条爬到 99% 卡住，3 秒后弹出「加载失败」 |

| 4 | 权限窗 | 勾选框已勾上且点不掉；允许 / 拒绝都继续 |

| 9 | 终局 | 只有「再试一次」「游戏失败」两个大按钮 |
| 10 | 游戏失败 | 弹出 Windows 报错窗，点「确定」回到初始加载并开始下一轮 |
| 11 | 我认输 / ESC×5 | 一般画面弹出「唉~回家吃饭吧你还是」，点「好吧」进入结束页；silly 画面中 ESC×5 直接进入终局页 |
| 12 | 刷新页面 | 回到初始加载，弹窗与统计清空 |
| 13 | 连点按钮 | 不会叠出重复弹窗，同屏最多 3 个 |
| 14 | 手机 / 小屏 | 弹窗不超出屏幕、始终可点按钮关闭（建议真机验证） |

## 边界说明

- 假权限、假报错、假 Windows 提示均为网页自绘界面，不会触发任何真实系统行为。
- 不收集、不上传、不保存任何数据；刷新即清零。
- 当前版本按需求**不包含「你被整了」的揭晓文案**，只保留可退出的出口。若以后想加回玩笑说明，可修改 `renderEnd`。
